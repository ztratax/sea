# ZTRATAX OCEAN — The Great Current

Prototipe game browser sederhana untuk menguji mekanik prediksi arus laut. Tanpa framework, server, atau dependensi.

## Cara menjalankan

Buka `index.html` di browser, atau unggah file ke repository GitHub dan aktifkan **Settings → Pages → Deploy from a branch → main / (root)**.

## Gameplay

- 1 pemain manusia melawan 2 komputer, 8 ronde.
- Pilih arah; arus acak diungkap dari 8 kartu (2 untuk tiap arah).
- Nilai dasar: cocok arus 3, berlawanan 0, samping 1.
- Jika beberapa pemain memilih arah sama, poin dibagi rata lalu dibulatkan ke bawah.
- Masing-masing pemain punya 1 Power Move untuk memutar arah 90° setelah arus terungkap.
- Skor tertinggi setelah ronde ke-8 menang.
